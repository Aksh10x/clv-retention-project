# CLV & Retention Intelligence Platform

## Goal
A portfolio-grade data science project for placement interviews (SDE/Data 
Analyst roles). Code quality, clarity, and explainability matter as much 
as results — I need to be able to defend every design choice in interviews.

## Standards
- Type hints on all functions
- Docstrings explaining the "why", not just the "what"
- No magic numbers — constants named and explained
- Modular: each stage should run independently via CLI args
- Log key metrics at each stage to outputs/metrics.json
- Prefer readable code over clever code
